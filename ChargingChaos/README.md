# ChargerChaos

## What Is It?
Users control a phone player to get their battery to 100% and win
Projectiles fall from the sky and users must collect certain ones
The game features lightning bolts to increase battery
At the same time, there are viruses that will decrease battery

## Controls
Use A/D to move Left/Right or use Left/Right Arrow Keys to move Left/Right

## Features
As the game progresses, the level increases
This makes the amount of falling projectiles to increase
Win by reaching 100% battery or lose by hitting 0% battery
